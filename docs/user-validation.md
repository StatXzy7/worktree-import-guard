# First-use pilot — not yet executed

Recruitment draft (do not send without authorization): “Do you have a Python project
with pytest tests? We are looking for people who have never used worktree-import-guard
to try its instructions without live coaching. You can use a disposable sample. We
want to understand installation and interpretation problems, not collect your code.”

Invite 10 first-time users: roughly half CLI users and half existing local coding-agent
users, including some unfamiliar with Python packaging. Participation is voluntary;
do not collect source, full local paths, credentials, or private test output.

Give each participant the public README and its actual available installation channel.
Ask them to:

1. Explain what the tool checks and what it cannot establish.
2. Install/import the chosen entry and run Demo without undocumented author help.
3. Check a real project or a controlled wrong-source fixture.
4. Explain tests passed/failed independently of source PASS/FAIL/UNKNOWN.
5. In the next relevant worktree/environment-change scenario, observe whether they
   choose to use it again without prompting. Do not require daily use.

Record the first obstacle and any author intervention. After the attempt, ask what
would stop them retaining the tool. Internal goals: 8/10 independently finish,
8/10 explain both results correctly, and at least 3 voluntarily reuse it in a second
relevant scenario. These are product targets, not results or statistical claims.

Blank record (one row per consenting participant; use anonymous IDs):

| ID | CLI/Skill; prior packaging experience | Task/environment | Install completed / attempted | Environment selected / attempted | Mapping completed / attempted | Both results understood / attempted | Author help and first obstacle | Second relevant opportunity / spontaneous reuse |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| | | | | | | | | |

Keep denominators for each stage; mark not attempted instead of counting it as success.
Compare manual input and author assistance for CLI versus Skill, while recording
task/familiarity differences. Ten people cannot establish causal superiority or
statistical significance. Demo success, bot installs, stars and downloads are not
adoption evidence. Current status: **NOT_STARTED; no participants or outcomes recorded**.
