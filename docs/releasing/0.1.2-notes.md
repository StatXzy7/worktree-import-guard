# 0.1.2 — PyPI release

First PyPI release that includes reusable `--doctor`, public README/PyPI alignment, structured
Skill preflight states, and shared preview/candidate compatibility checks. Version 0.1.1 on the
index predates those changes; upgrade with:

```text
python -m pip install --upgrade worktree-import-guard==0.1.2
```

Recommended install in the project's existing pytest environment:

```text
python -m pip install worktree-import-guard==0.1.2
```

See [0.1.1-notes.md](0.1.1-notes.md) for the earlier candidate history. The experimental Codex
Skill remains `HOST_UNVERIFIED` on the reference host.
