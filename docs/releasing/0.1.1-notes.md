# 0.1.1 candidate — not published

Adds an experimental local Codex Skill that reuses saved targets, runs the existing
detector once in a confirmed environment and checks that the fresh JSON belongs to
that invocation. Tests and source outcomes remain separate. CLI version 0.1.1 can
upgrade normally from same-version 0.1.0 previews; report schema remains v2.

After authorized publication and real-index smoke checks, the recommended install
will be the existing project Python running:

```text
python -m pip install worktree-import-guard==0.1.1
```

Until then use README's verified source preview. The Skill has independent
compatibility constraints; see its workflow reference. No external user adoption
is claimed.

## Release copy (draft)

**Python debugging:** “Your tests pass, but did pytest import the checkout you
actually edited? `wt-import` runs beside your existing pytest and shows expected vs
observed source paths—without repairing your environment.”

**AI coding / test-source verification:** “Before trusting a green test run from a
coding agent, bind one guarded pytest to a fresh report. The experimental Codex Skill
reuses your saved targets and separates test outcome from source PASS/FAIL/UNKNOWN.”
